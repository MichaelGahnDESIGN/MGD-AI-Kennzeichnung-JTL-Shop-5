# MGD AI Labelling for JTL-Shop 5

This public project provides the foundation for a JTL-Shop plugin intended to label AI-generated content transparently. The labelling feature itself is not implemented in this revision.

## Requirements

- JTL-Shop 5.7.2 or newer
- PHP 8.1 or newer

## Development checks

After `composer install`, run `composer test`, `composer analyse`, and `composer style`. The plugin directory is `plugin/MGD_AI_Kennzeichnung/`.
