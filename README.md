# MGD AI Kennzeichnung für JTL-Shop 5

Dieses öffentliche Projekt stellt das Grundgerüst für ein JTL-Shop-Plugin bereit, das künftig KI-generierte Inhalte transparent kennzeichnen soll. Die eigentliche Kennzeichnungsfunktion ist in diesem Stand noch nicht implementiert.

## Voraussetzungen

- JTL-Shop ab Version 5.7.2
- PHP ab Version 8.1

## Entwicklungsprüfung

Nach `composer install` stehen `composer test`, `composer analyse` und `composer style` zur Verfügung. Das Pluginverzeichnis lautet `plugin/MGD_AI_Kennzeichnung/`.
