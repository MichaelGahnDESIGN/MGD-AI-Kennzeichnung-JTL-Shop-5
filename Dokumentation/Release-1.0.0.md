# Release 1.0.0

Erste funktionsfähige Version für JTL-Shop ab 5.7.2 und PHP ab 8.1. Enthalten sind lokale Bildverwaltung, transparente Labels, AI-Philosophie-Portlet, geschützte Administration, datensparsame optionale Updatehinweise und eine sichere Deinstallation.

Vor der Installation sind Pflichtbackup, SHA-256-Prüfung und ein Wartungsfenster erforderlich. Das Repository und der Release bleiben bis zur abgeschlossenen Live-Abnahme privat.
